### Навигация
- Главное окно содержит Frame и панель с тремя кнопками
- При нажатии на кнопку в Frame загружается соответствующая страница

### Особенности реализации
- Все поля ввода проверяются на корректность (заполненность, тип данных)
- Результат выводится в ReadOnly-поле
- Кнопка "Очистить" сбрасывает все поля
- При наведении на элементы появляются всплывающие подсказки (ToolTip)
